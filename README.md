## Description of Work

This notebook demonstrates and compares multiple tokenization approaches on a short English paragraph.

1. Naïve Space-Based Tokenization  
   - Uses simple whitespace splitting.
   - Does not handle punctuation correctly.

2. Manual Tokenization  
   - Uses regular expressions to handle punctuation and word boundaries.
   - Improves accuracy over naïve tokenization.

3. Tool-Based Tokenization  
   - Implements a rule-based tokenizer using Python's built-in re module.
   - Used as an NLP tool alternative.

4. Comparisons  
   - Naïve vs Manual tokenization  
   - Manual vs Tool-based tokenization  
   - All outputs are visible directly in the notebook.

5. Multiword Expressions (MWEs)  
   - Examples include:
     - Natural Language Processing
     - human language
     - first step

6. Reflection  
   - Discusses challenges of tokenization, punctuation, and MWEs.
   - Compares tokenization complexity in English.
